# フィールドコレクション

マップと進捗画面から「スタンプ・ステッカーを見る」を開くと、各フィールドのコレクションを確認できます。マップを展開したときも同じ情報を表示します。

2026-10-20に共有された報酬仕様は、HR上昇で壁紙、フィールド報酬としてオリジナルステッカー（現地のフォトスポットで交換）、武器作成で攻撃ダメージ増加です。この変更では担当範囲のフィールド報酬表示を反映しています。HR報酬・武器作成の既存画面には旧表記が残っており、別担当の変更と統合する必要があります。

フィールドとクエストの対応は `src/data/maps.ts` の `questIds` で定義します。従来のマップの順序対応（1〜3号館と quest-001〜003）を明示したもので、表示順が変わっても記録を取り違えません。4号館は対応クエストが未定義なので「準備中」です。

スタンプは既存のクエストの `completed` と `goldCrown` から表示するため、保存済みの討伐もそのまま反映します。報酬を受け取る前のバトル結果だけではスタンプを付与しません。

ステッカーの受取記録は `obtainedFieldNoveltyIds` に保存するフィールドIDです。スタンプとは独立しており、討伐・武器作成では更新しません。古い保存データは未獲得として読み込みます。今回は表示のみのため受取操作・配布条件・在庫APIは実装していません。仕様書には「全モンスターの討伐or調査」と「全スタンプ獲得」の両方が記載されているため、交換条件は確定仕様とのすり合わせが必要です。

ステッカーの実物画像は未提供のため、共通のステッカーアイコンを表示します。画像は `src/data/maps.ts` の `novelty.image`、名称・説明は `novelty.name` / `description`、交換場所は `novelty.redemptionLocation` に設定できます。共通アイコンは実物のデザインとして扱いません。
