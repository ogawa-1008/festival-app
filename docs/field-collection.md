# フィールドコレクション

マップと進捗画面から「スタンプ・ノベルティを見る」を開くと、各フィールドのコレクションを確認できます。マップを展開したときも同じ情報を表示します。

フィールドとクエストの対応は `src/data/maps.ts` の `questIds` で定義します。従来のマップの順序対応（1〜3号館と quest-001〜003）を明示したもので、表示順が変わっても記録を取り違えません。4号館は対応クエストが未定義なので「準備中」です。

スタンプは既存のクエストの `completed` と `goldCrown` から表示するため、保存済みの討伐もそのまま反映します。報酬を受け取る前のバトル結果だけではスタンプを付与しません。

ノベルティの受取記録は `obtainedFieldNoveltyIds` に保存するフィールドIDです。スタンプとは独立しており、討伐・武器壁紙交換では更新しません。古い保存データは未獲得として読み込みます。今回は表示のみのため受取操作・配布条件は実装していません。

実物の名称・画像が未提供のため、ノベルティ欄にはフィールド名、共通のギフトアイコン、会場での確認案内を表示します。正式な内容は `src/data/maps.ts` の `novelty.name` / `description` / `image` に設定できます。画像未設定時はギフトアイコンを表示し、実物の画像として扱いません。
