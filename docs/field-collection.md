# フィールドコレクション

1つの建物（号館）にはフォトスポット1つ、対戦モンスター1体を配置します。同じ会場（東京・大阪・名古屋）の異なる3校舎を回り、討伐または調査の報酬を受け取ってスタンプを3つ集めると、ステッカーを合計1枚受け取れます。

アプリでは最初にエリア（大阪・東京・名古屋）を選びます。ホームのクエスト一覧には、選んだエリアの全校舎のクエストを表示し、そのエリアの校舎のQRコードはどれでも読み取れます。ほかのエリアのQRコードは読み取れません。校舎名の地名は `frontend/src/data/campuses.ts` の `buildingPrefix` で会場ごとに設定します。

大阪では心斎橋1号館がリオレウス、心斎橋2号館がアルシュベルド・アイルー（1つのフォトスポット・対戦枠）、心斎橋3号館がメルゼナです。残りの配置は各会場の `frontend/src/data/campuses/*.ts` を参照してください。フォトスポットの名称から対戦相手を生成し、1つの建物に複数のクエストを登録しない構成にしています。

討伐・調査のどちらも、その校舎のスタンプ1つとして数えます。同じモンスターへの再挑戦、練習用クエスト、別会場のクエストは追加スタンプに数えません。報酬受取前のバトル結果だけではスタンプを付与しません。

スタンプ3つがそろったら、訪問済み校舎のフォトスポットから好きな絵柄1枚を選んで交換します。スタンプは記録として残りますが、交換後は全校舎で追加交換できません。交換場所の校舎IDを `obtainedFieldNoveltyIds` に保存し、APIによる在庫減算に成功したときだけ受取記録を付けます。保存データに複数校舎の旧受取記録がある場合も、そのまま保持し、追加交換はできません。記録は従来どおり同じ端末・ブラウザの会場別保存データで管理します。

会場のQRコードは `QUEST_<会場名の大文字>_<号館番号>` です。例：大阪1〜3号館は `QUEST_OSAKA_1`、`QUEST_OSAKA_2`、`QUEST_OSAKA_3`。練習用の `QUEST_001` は本番用とは別です。会場に掲示するQRコードにもこの値を使用してください。

モンスター画像は現在ジンオウガのみ提供されています。他の対戦枠は共通のターゲットアイコンで表示します。実物ステッカーの画像は未提供のため、共通のステッカーアイコンを使用します。
