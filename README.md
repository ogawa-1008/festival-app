# モンスターハンターフェスティバル

会場を歩きながらクエストに挑戦し、素材を集めて特典と交換する、モンスターハンターフェスティバル向けの体験アプリです。QRコードを起点に、狩猟・報酬の獲得・コレクションの確認までを一つの流れで楽しめます。

## リポジトリ構成

npm workspaces を使ったモノレポ構成です。

```
.
├── frontend/   # フロントエンド（React + TypeScript + Vite）
└── backend/    # API（今後実装予定）
```

## アプリ概要

参加者はホーム画面でクエストを選び、会場に設置されたQRコードを読み取って狩猟を開始します。バトルはじゃんけん形式です。勝利すると素材とハンターランク経験値を獲得でき、討伐済みのクエストはコレクションに記録されます。

集めた素材は進行状況画面で確認できます。必要な素材がそろうと、スマホの壁紙と交換できます。交換後は画面をスタッフへ提示することで、会場での特典受け取りにつなげられます。

ゲームの進行状況はブラウザのローカルストレージに保存されるため、同じ端末・ブラウザであれば画面を閉じても続きから利用できます。

## 主な機能

- クエスト一覧とフィールドマップの表示
- カメラを使ったクエスト用QRコードの読み取り
- じゃんけんによる狩猟バトル
- 勝敗に応じた素材・経験値の獲得と討伐記録
- 素材、討伐スタンプ、活動履歴のコレクション表示
- フィールドごとのスタンプとステッカーの獲得状況・フォトスポットでの交換案内（マップ・進捗・コレクションから確認）
- 素材を消費する特典（スマホ壁紙）交換

## 画面の流れ

1. エリア（大阪・東京・名古屋）を選ぶ
2. ホーム画面でクエストを選ぶ（選んだエリアの全校舎のクエストが並ぶ）
3. QRコードを読み取り、確認画面で「狩猟を始める」を押す
4. バトルでモンスターに挑戦する
5. 結果画面で報酬を受け取る
6. 進行状況とコレクションを確認し、条件を満たしたら特典と交換する

## スタイルの共通定義（デザイントークン）

色・フォント・文字サイズ・余白・角丸・重なり順は `frontend/src/styles/global.css`（グローバル CSS）に CSS 変数として定義しています。アプリ全体の基本スタイルも同じファイルにあります。

- 新しく書く CSS では値を直接書かず、変数を使ってください（例: `color: var(--color-text);`、`z-index: var(--z-modal);`）
- ほぼ同じ色を新しく追加しないでください。近い色があればその変数を使います
- 新しい値がどうしても必要な場合は、`global.css` に変数を追加してから使います
- 変数の一覧と画面幅の区切り（360 / 380 / 430px）は `global.css` の先頭にまとめています

既存の画面の CSS は、画面ごとに順次この変数へ置き換えていきます。

## 起動方法

Node.js と npm を用意したうえで、リポジトリのルートで次のコマンドを実行します。

```bash
npm install
npm run dev
```

`npm run dev` は `frontend` ワークスペースの開発サーバーを起動します。`npm run build` / `npm run lint` も同様にルートから frontend を対象に実行できます。

frontend ディレクトリ直下で個別にコマンドを実行する場合は、事前にルートで `npm install` を済ませてから作業してください。

## 利用時の注意

QRコードを読み取るには、ブラウザでカメラの利用を許可してください。会場のQRコードはスマホの標準カメラでも読み取れます（アプリのURLが開きます）。QRコードの作り方は `docs/field-collection.md` を参照してください。進行状況を最初から試したい場合は、ブラウザのサイトデータから `monster-hunter-festival-game` のローカルストレージを削除してください。

## ハンターランク

新規利用時はHR0から開始し、報酬受取時に討伐で100 EXP、調査で30 EXPを獲得します。
次のHRに必要なEXPは `min(100 + 20 × 現在HR, 500)` で、100→120→140…と増加し、HR20以降は500 EXPで固定します。
ホームではHRの右側に、次のHRまでの進捗率と獲得済みEXP／必要EXPを表示します。
HR100で上限となり、バーは満タンの「MAX」表示になります。上限後も素材は獲得できます。

進行状況は既存の `monster-hunter-festival-game` キーでローカルストレージに保存します。
旧データは現在のHRを維持して自動移行します。旧必要EXPが500を超えていた場合は、次のHRまでの進捗率を維持するよう端数EXPを換算します（整数未満切り捨て）。
保存できない環境では通知を表示し、そのセッション内でプレイを継続できます。

結果画面で報酬を受け取ると、EXP数値とバーが増える演出を表示します。
ランクアップ時は一度バーが満タンになり、次のHRへ余剰EXPを繰り越します。
報酬の保存は受取時に行うため、演出の途中でホームへ戻っても獲得EXPは保持されます。
