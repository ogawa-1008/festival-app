# モンスターハンターフェスティバル

会場を歩きながらクエストに挑戦し、素材を集めて特典と交換する、モンスターハンターフェスティバル向けの体験アプリです。QRコードを起点に、狩猟・報酬の獲得・コレクションの確認までを一つの流れで楽しめます。

## リポジトリ構成

npm workspaces を使ったモノレポ構成です。

```
.
├── frontend/   # フロントエンド（React + TypeScript + Vite）
└── backend/    # API（今後実装予定）
```

## アプリ概要

参加者はホーム画面でクエストを選び、会場に設置されたQRコードを読み取って狩猟を開始します。バトルはじゃんけん形式です。勝利すると素材とハンターランク経験値を獲得でき、討伐済みのクエストはコレクションに記録されます。

集めた素材は進行状況画面で確認できます。必要な素材がそろうと、武器のピンバッジと交換できます。交換後は画面をスタッフへ提示することで、会場での特典受け取りにつなげられます。

ゲームの進行状況はブラウザのローカルストレージに保存されるため、同じ端末・ブラウザであれば画面を閉じても続きから利用できます。

## 主な機能

- クエスト一覧とフィールドマップの表示
- カメラを使ったクエスト用QRコードの読み取り
- じゃんけんによる狩猟バトル
- 勝敗に応じた素材・経験値の獲得と討伐記録
- 素材、討伐スタンプ、活動履歴のコレクション表示
- 素材を消費する特典（ピンバッジ）交換

## 画面の流れ

1. 初回は校舎を選択し、確認画面で決定する
2. ホーム画面でクエストを選ぶ
3. QRコードを読み取る
4. バトルでモンスターに挑戦する
5. 結果画面で報酬を受け取る
6. 進行状況とコレクションを確認し、条件を満たしたら特典と交換する

校舎選択画面は `/start` から開けます。選択した校舎はゲームの進行状況と一緒に保存され、次回はホームから再開します。ホームのメニューから校舎を選び直せます。現在のクエスト・マップデータは全校舎で共通です。

## 開発環境

- React 19
- TypeScript
- Vite
- React Router
- html5-qrcode

## 起動方法

Node.js と npm を用意したうえで、リポジトリのルートで次のコマンドを実行します。

```bash
npm install
npm run dev
```

`npm run dev` は `frontend` ワークスペースの開発サーバーを起動します。`npm run build` / `npm run lint` も同様にルートから frontend を対象に実行できます。

frontend ディレクトリ直下で個別にコマンドを実行する場合は、事前にルートで `npm install` を済ませてから作業してください。

### backend について

`backend/` は今後追加するAPI用のワークスペースです。現時点では実装がないため、詳細は `backend/README.md` を参照してください。

## 利用時の注意

QRコードを読み取るには、ブラウザでカメラの利用を許可してください。進行状況を最初から試したい場合は、ブラウザのサイトデータから `monster-hunter-festival-game` のローカルストレージを削除してください。
